# tax-moadian — Iranian tax authority e-invoicing (سامانه مودیان) (L5; regional ir; requires sales, accounting-gl; optional item-master, party-master)

**CRITICAL** This module must follow the OFFICIAL technical documentation of the Iranian Tax Authority (Moadian). Do NOT guess algorithms, encryption/signature schemes, endpoints, field names or invoice schemas. Use only the spec documents the maintainer places in `docs/external/moadian/` (if absent: build everything behind interfaces with a MOCK adapter and mark gaps in `docs/external/moadian/TODO.md`).
**Entities** TaxProfile{company, tax_memory_id(شناسه حافظه مالیاتی), economic_code, certificate/key references (secret storage, never in DB plaintext), environment[sandbox|production]}; ItemTaxMap{item_id, goods_service_id(شناسه کالا/خدمت), vat_rate_ref, unit_code}; PartyTaxInfo (read from party-master); TaxInvoice{sales_invoice_ref, invoice_type/pattern ref, subject (original|correction|cancel|return), unique_tax_id(شماره منحصربه‌فرد), reference_number, status[draft|ready|queued|sent|accepted|rejected|inquiry_pending|cancelled], payload snapshot(json), response snapshot, error_codes[], attempts}; ErrorCatalog (data); SubmissionBatch.
**Rules** status machine driven by adapter responses; idempotent submission with retry/backoff via outbox; validation of mandatory fields before send using schema from official docs (as data); corrections/cancel/return invoices reference the original; no editing of accepted invoices (only issue correction/return); batch send and inquiry job; audit of every request/response (without secrets); alerts for rejected invoices; key/certificate storage via a pluggable secret store (env/file outside web root).
**Events out** tax-moadian.invoice.queued|accepted|rejected. **In** sales.invoice.issued|cancelled, sales.return.posted.
**Service contract** MoadianService: statusOf(salesInvoiceId), submit(invoiceId), inquire(referenceNumber), validate(invoiceId): ValidationResult, adapter(): MoadianAdapter (interface with MockAdapter).
**Permissions** tax-moadian.invoice.view|submit|retry|correct, tax-moadian.profile.manage, tax-moadian.itemmap.manage.
**Screens** submission queue/status board, invoice detail with request/response, rejected-fix workflow, item→شناسه کالا/خدمت mapping grid with import, profile & environment settings, VAT summary reports.
**AI** next_action (explain rejection and suggest fix, proposal only), anomaly (mapping inconsistencies). redact: all tax ids when external provider.
**Datasets** tax_invoices_status.
