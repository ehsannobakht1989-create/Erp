# Definition of done

The authoritative per-module definition is `docs/MASTER-PLAN.md`, sections 7 and 9. A module can be marked `done` only after the independent depth gate scores at least 80 overall, at least 60% in every category, reports no anti-gaming violations, and the module tests pass. The gate and Laravel core have not yet been built. Legacy tests or a legacy manifest declaration alone are not evidence of completion.
