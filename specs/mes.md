# mes — Shop-floor execution (L4; requires work-order, routing, asset-registry; optional scheduling, quality-inspection, attendance, api-webhooks)

**Entities** Terminal{work_center_id,type[touch|barcode|tablet],login_mode[pin|badge|none],active}; Dispatch(derived from scheduling or WO ops); OpRun{wo_operation,operator,start,pause[],stop,state[running|paused|done]}; Report{op_run,qty_good,qty_scrap,qty_rework,reason_codes,lot_in[],lot_out[],notes,at}; ConsumptionScan{wo,component,lot,qty}; DowntimeEvent{work_center,start,end,reason_code,category,source[operator|machine|auto]}; ReasonCode{type[scrap|downtime|rework|pause],tree}; MachineTag{work_center,tag,type[counter|state|temperature…],mapping,scale}; Andon{type[maintenance|quality|material|supervisor],work_center,status}; ShiftNote.
**Rules** operator must be qualified for operation if skills enforced (hr-core skills optional); one active run per operator/work-center rules (configurable parallel); quantity reports idempotent and forward to WorkOrderService::reportOperation; backflush/scan consumption validates lot against traceability needs & quality status (IsReleased); machine data ingestion via api-webhooks endpoint with tag mapping and debouncing (auto start/stop downtime from machine state); andon triggers notifications and optional CMMS work request; in-process inspection prompt triggers quality-inspection IPQC lot per plan; offline-tolerant client queue (setting) with conflict-safe replays.
**Events out** mes.operation.started|paused|completed, mes.production.reported, mes.downtime.started|ended, mes.andon.raised|closed. **In** scheduling.schedule.published, work-order.wo.released, quality-inspection.lot.decided, asset-registry.asset.status_changed.
**Service contract** MesService: runningOps(workCenter?), oeeInputs(workCenter,range), downtime(workCenter,range), tagValue(workCenter,tag), operatorStatus(employee).
**Permissions** mes.terminal.use, mes.report.correct, mes.reasoncode.manage, mes.tag.manage, mes.andon.manage, mes.dashboard.view.
**Screens** operator terminal (large buttons, Persian, scan-first: job list → start → report → downtime reason → finish), supervisor board (live status per work center), andon board, tag mapping admin, reason code tree, corrections audit, shift handover, TV dashboard.
**AI** anomaly (rate drops, suspicious reports), assistant for operators (work instructions Q&A over attached documents, read-only), summarize shift.
**Iran** Persian touch UI, large fonts, works on cheap Android tablets and industrial PCs; PLC integration through gateway posting to webhook endpoint.
