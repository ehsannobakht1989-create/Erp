# costing — Cost accounting (L5; requires work-order, inventory, accounting-gl; optional bom, routing, payroll, fixed-assets, mes, pricing)

**Entities** CostElement{code,type[material|labor|machine|overhead|subcontract|landed]}; CostRate{work_center|cost_center,element,rate_per_hour|per_unit,effective_from,basis[labor_hr|machine_hr|units|material_pct]}; StandardCost{item,version,elements{},status[draft|approved|active],effective_from,roll_up_log}; ActualCost{wo_id,element,amount,qty,detail refs}; OverheadPool{cost_center,period,amount,driver,absorption_rate}; WipSnapshot{period,wo_id,material,labor,overhead,total}; VarianceRecord{wo_id|item,type[price|usage|efficiency|rate|overhead|yield|mix|scrap],amount}; ValuationMethod{item|category,method[standard|moving_average|fifo|lot_specific]}; LandedCostAllocation{receipt_line,charges[],basis[value|qty|weight|volume]}; CostRun{period,status,steps,journal_requests}; ItemCostHistory.
**Rules** standard roll-up: multi-level via BomService + RoutingService.costRates + overhead rates, includes scrap/yield and by-product credit; simulation mode doesn't activate; activation by approval; actual WO cost = issued material at inventory valuation + labor/machine hours (MES/WO reports × rates) + absorbed overhead + subcontract (PO/invoice); by-product allocation per BOM %; WIP at period end = costs accumulated − completed; variances on close; landed cost allocation of PO charges (freight, customs, insurance, ...) increases receipt valuation and is communicated to inventory (cost adjustment movement) — with currency rate at receipt; COGS on issue for sales from valuation; period cost run is idempotent & restartable; ALL posting via JournalRequest (WIP, FG, COGS, variances, overhead absorbed/applied, price variance) using default posting rule pack; period lock respected; recalc of moving average on backdated receipts handled with controlled re-valuation job.
**Events out** costing.cost.updated{item,type}, costing.wo.costed, costing.run.completed, costing.variance.recorded. **In** work-order.wo.closed|material.issued|output.received, inventory.receipt.posted|issue.posted|adjustment.posted, mes.production.reported, purchase-order.po.* & ar-ap.invoice.posted (landed/price), payroll.run.approved (labor rate feed, aggregated), fixed-assets.depreciation.posted (machine rate feed), accounting-gl.period.closed.
**Service contract** CostingService: itemCost(item,date,kind[standard|actual|latest]), woCost(woId), wipValue(period), margin(item,date,price), simulate(itemFilter,params), valuationOf(item,warehouse), runPeriod(period,dryRun).
**Permissions** costing.standard.view|manage|approve, costing.rate.manage, costing.run.execute|approve, costing.report.view, costing.valuation.manage.
**Screens** standard cost roll-up (tree with element breakdown), simulation compare, rate tables, overhead pools & absorption setup, WO actual vs standard, variance analysis (waterfall/drill), WIP report, cost run wizard (preview→post), valuation settings, landed cost allocation screen, item cost history.
**AI** anomaly (cost spikes, unusual variance), nl_report ("why did unit cost of X rise?" — explain via variance drivers read-only), forecast cost trend (python). Margin data redaction setting for external providers.
**Iran** inflation-heavy costs: support frequent re-costing and revaluation runs; currency-linked raw material price effects shown separately; hyperinflation-style adjusted costing as optional report (settings).
