# payroll — Payroll (L3; requires hr-core, attendance, accounting-gl; optional treasury, loans)

**Entities** SalaryStructure{components[]}; PayComponent{code,name,type[earning|deduction|employer_cost],calc[fixed|formula|rate|attendance_based],taxable,insurable,gl_key}; EmployeeSalary{employee,structure,effective_from,values{}}; PayrollRun{period,status[draft|calculated|reviewed|approved|paid|locked],lines}; PayslipLine; TaxTable{year,brackets[]}; InsuranceRule{year,employee_pct,employer_pct,ceiling,floor}; Loan{employee,amount,installments,schedule}; OneOffPayment{bonus,عیدی,...}; Severance calc; PaymentFile.
**Rules** run reads attendance.period.closed summaries + employee salary effective on dates (prorating for hire/termination); formulas via safe expression engine; tax & insurance computed from versioned tables (admin-maintained data, never hard-coded); loan installments auto-deducted with schedule update; negative net blocked/flagged; retro adjustments in later runs; lock period after approval; payslip immutable snapshot; changes after approval via adjustment run.
**Events out** payroll.run.approved{totals by cost center & component→journal request}, payroll.run.paid, payslip.published. **In** attendance.period.closed, hr-core.employee.terminated (final settlement draft).
**Service contract** PayrollService: payslip(employee,period), costByCostCenter(period), headcountCost(filter) (restricted), previewRun(period).
**Permissions** payroll.structure|component|table.manage, payroll.run.view|calculate|approve|pay|lock, payroll.payslip.view-own|view-all, payroll.loan.manage — all high-sensitivity.
**Screens** salary structure designer, employee salary assignment/mass update, run wizard (calculate→review exceptions→approve), payslip view/print/own-portal page, bank payment file export (generic CSV/Sheba list), insurance list (لیست بیمه) and tax report exports, loans, one-off payments, labor cost dashboard (restricted).
**AI** assistant only on aggregate/anonymized data; anomaly on run (outlier net pay, missing attendance); AI NEVER receives per-employee identifiers or amounts unless provider=python/local and capability explicitly enabled; `redact: *`.
