# sales — Quotation, order, delivery, invoice (L2; requires item-master, party-master, pricing; optional inventory, accounting-gl, tax-moadian)

**Entities** Quotation(پیش‌فاکتور){validity,...}; SalesOrder{number,customer_id,date,currency,payment_terms,salesperson_id,delivery_terms,status[draft|confirmed|partially_delivered|delivered|invoiced|closed|cancelled]}; SOLine{item,qty,uom,price,discount,tax_code,warehouse,promised_date,delivered_qty,invoiced_qty,reserved_qty}; Delivery(حواله){so_refs,warehouse,vehicle,driver,status[draft|requested|picked|shipped|delivered]}; SalesInvoice{customer,lines,taxes,total,serial_no,status[draft|issued|sent_to_tax|cancelled],moadian_ref?}; SalesReturn/CreditNote; Salesperson; Territory.
**Rules** credit check on confirm (limit, overdue balance via ArApService optional, override approval); price via PricingService (manual override needs permission); stock availability & reservation on confirm (setting); partial deliveries/invoicing; invoice cannot exceed delivered (setting); numbering sequences per fiscal year; cancel only if no downstream docs; return requires reference and reason, restocks to quarantine by default.
**Events out** sales.order.confirmed|cancelled, sales.delivery.requested|posted, sales.invoice.issued|cancelled, sales.return.posted. **In** inventory.issue.posted (delivered_qty), ar-ap.payment.allocated (status), tax-moadian.invoice.accepted|rejected.
**Service contract** SalesService: openOrders(customer?,item?), backlog(item) (for MRP), invoiceTotals(period,filter), find(id).
**Permissions** sales.quotation|order|delivery|invoice|return.view|create|update|approve|cancel, sales.price.override, sales.credit.override.
**Screens** quotation→order→delivery→invoice flow with one-click conversions, order board (kanban by status), customer 360 widget, backlog report, sales by customer/item/salesperson, margin report (if costing), print (پیش‌فاکتور/فاکتور/حواله) templates.
**AI** autofill (order from customer message/email text, proposal), forecast hook (series for demand-forecast), anomaly (credit risk, unusual discount), nl_report, next_action (follow up quote). redact: cost/margin fields for external provider unless allowed.
**Iran** invoice fields required for مودیان (serial, unique tax id, buyer ids, item/service codes شناسه کالا/خدمت, VAT lines) stored but submission is tax-moadian's job; Jalali dates; cash/cheque/credit sale types.
