# inventory — Warehouse & stock (L2; requires item-master, org-structure; optional party-master, quality-inspection, accounting-gl)

**Entities** Warehouse{code,name,type[raw|wip|finished|spare|quarantine|scrap|transit|consignment],unit_id,is_active}; Location{warehouse_id,zone,rack,bin,code,capacity,type}; StockLedger (append-only){id,doc_type,doc_id,line_id,item_id,warehouse_id,location_id,lot_id,serial_id,qty_in,qty_out,uom,qty_base,unit_cost?,value?,status_bucket[available|quarantine|blocked|in_transit|reserved],posted_at,period_id}; Lot{item_id,lot_no,supplier_lot,mfg_date,expiry_date,retest_date,attributes}; Serial{item_id,serial_no,lot_id,status,location}; StockBalance (derived/maintained){item,warehouse,location,lot,serial,bucket,qty}; Reservation{item,warehouse,lot?,qty,source_type,source_id,expires_at}; Docs: Receipt, Issue, Transfer(two-step: ship→in_transit→receive), Adjustment, StockCount(sheet,freeze,count1/2,variance approval), Return; each with header/lines, numbering via NumberingService, workflow draft→submitted→approved→posted→cancelled(reversal).
**Rules** posting is atomic & immutable (corrections via reversal docs); balance lock per (item,warehouse,location,lot) with SELECT…FOR UPDATE; negative stock controlled by setting per warehouse; lot/serial required per item tracking flags from item-master; expiry: FEFO suggestion, block expired issue unless override; UoM conversion via ItemMasterService; backdated posting allowed only within open period and by permission; reservations reduce available; quarantine bucket excluded from available; transfer in-transit stock owned by neither warehouse; stock count freezes movements for counted scope; period lock via accounting period event (optional).
**Events out** inventory.receipt.posted{doc,lines[item,qty,lot,cost?,source_ref]}, issue.posted, transfer.shipped|received, adjustment.posted, stock.first_posted(item), stock.below_min, reservation.created|released. **In** purchase-order.po.approved (expected receipts list), sales.delivery.requested (create issue draft), quality-inspection.lot.decided (move bucket), production events via InventoryService (work-order consumption/receipt), cmms.workorder.parts_requested (optional).
**Service contract** InventoryService: getBalance(item,filters), getAvailable(item,warehouse), hasStock(item), reserve(dto), release(id), postMovement(dto, idempotencyKey) (used by production/cmms/sales with permission check), suggestPicking(item,qty,warehouse,strategy[fefo|fifo|lot]), getLot(id), expiringLots(days), valuationFeed(period) (qty movements for costing).
**Permissions** inventory.warehouse.manage, inventory.receipt|issue|transfer|adjustment|count.view|create|approve|post|reverse, inventory.balance.view, inventory.reservation.manage, inventory.backdate.
**Screens** warehouses/locations, balances (pivot by item/warehouse/lot, filters, export), document list+forms for each doc type, scan-friendly screens (barcode input first), stock card (item ledger), expiry dashboard, count sheet (print + entry), variance review, aging stock report, ABC helper report.
**AI** assistant (stock questions via tools), anomaly (unusual adjustments/shrinkage/negative patterns), forecast hook (provides time series to demand-forecast via dataset query), autofill (suggest location putaway, lot from supplier text). proposals: transfer/reorder suggestions only.
**Edge** concurrent posting, partial receipts vs PO tolerance (read PO via PurchaseOrderService if enabled), split lots, unit conversions rounding, serial uniqueness, reversal of transferred stock, period close.
**Iran** رسید انبار / حواله خروج / برگه انتقال print templates, کاردکس report (Kardex), Persian digits on labels.
