# cmms — Maintenance management (L3; requires asset-registry; optional inventory, hr-core, purchase-request)

**Entities** WorkRequest{asset,reported_by,description,priority,status[new|accepted|rejected|converted]}; WorkOrder{number,type[corrective|preventive|predictive|inspection|project],asset,priority,status[draft|planned|released|in_progress|waiting_parts|completed|closed|cancelled],planned_start/end,actual_start/end,assignees[],failure_code,cause_code,action_code,downtime_min,safety_flags,checklist_results}; WOTask{seq,description,duration_est,done}; WOPartUse{item,qty,warehouse,issue_doc_ref}; WOLabor{employee,hours,rate}; PMPlan{asset|class,trigger[calendar|meter|condition],interval,lead_time,checklist,estimated_hours,parts[]}; FailureCode tree; Technician skills/availability (via hr-core refs); Downtime log.
**Rules** PM generation job (cron via events:work) creates WOs ahead of due; meter-based triggers from asset-registry readings; priority/SLA clocks via workflow; parts: reserve/issue via InventoryService (optional) — if absent, record manually; completing WO requires failure/cause codes for corrective; closing computes cost (labor+parts+external) and emits cost event; asset status auto-down/up with WO state (setting); backlog & overdue flags.
**Events out** cmms.workorder.created|released|completed|closed, equipment.down|restored, parts.requested|shortage. **In** asset-registry.meter.updated, inventory.stock.* (parts availability), hse.incident.reported (optional).
**Service contract** CmmsService: openOrders(asset), pmDue(range), downtime(asset,range), mttrMtbf(asset|class,range), costByAsset(range).
**Permissions** cmms.request|workorder|pm|failurecode.view|create|update|approve|close, cmms.report.view.
**Screens** request portal (simple mobile form), planner board (calendar/kanban), WO form (tasks, parts, labor, checklist, photos), PM plans, my jobs (technician mobile view), downtime log, reports (MTBF/MTTR/availability, backlog, cost, top failures Pareto), dashboard widgets.
**AI** assistant (suggest diagnosis/parts from failure history, read-only), forecast/anomaly hooks to failure-prediction (python), autofill (WO from request text, checklist from similar jobs), summarize asset history, next_action.
**Iran** متن‌های فارسی فرم‌ها (درخواست تعمیر/دستور کار), cost allocation to cost centers.
