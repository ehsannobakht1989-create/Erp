# accounting-gl — General ledger (L3; requires multi-company; optional all posting sources)

**Entities** Account tree (levels: کل group → معین → تفصیلی via dimensions) {code,name,type[asset|liability|equity|revenue|expense|memo],nature[debit|credit],level,is_postable,currency_policy,requires_dimensions[]}; Dimension types (تفصیلی): party, employee, bank_account, cost_center, project, item, asset, custom; FiscalYear/Period{status[open|closed|locked]}; Journal (سند){number,date,type[opening|general|auto|closing|adjustment],status[temporary|permanent|reversed],source_module,source_ref,description,lines[]}; JournalLine{account_id,debit,credit,currency,fx_rate,dimensions{},description,quantity?}; PostingRule{event,conditions,lines_template(expression language),account_mappings,priority,active}; JournalRequest (inbox from other modules via event, status[pending|posted|failed|ignored]); Budget lines optional via budgeting.
**Rules** balanced journals; postable accounts only; dimension requirements enforced; period/lock checks; temporary docs editable, permanent require approval/number finalization (daily sequential numbering per setting); reversal creates mirror doc; auto-journals created from JournalRequest through PostingRules (idempotent per source_ref+event); failures go to a fix queue with reason; opening balances import; year-end closing (profit/loss transfer, carry-forward) as wizard with preview; multi-currency revaluation at period end.
**Events out** accounting-gl.journal.posted|reversed, period.closed|locked. **In** (via posting rules) inventory.receipt.posted, inventory.issue.posted, purchase.invoice.posted, sales.invoice.issued, treasury.*.posted, payroll.run.approved, fixed-assets.depreciation.posted, costing.* — each arrives as accounting.journal.requested payloads; rules map them. Ship a default rule pack (editable) per event.
**Service contract** AccountingService: requestJournal(JournalRequestDto), post(journalId), accountBalance(account,dims,asOf), trialBalance(filter), isPeriodOpen(date), resolveAccount(key) (named account roles like 'inventory.raw','ap.control').
**Permissions** accounting-gl.account.manage, journal.view|create|update|approve|reverse|delete, period.manage|close|lock, rule.manage, report.view, opening.import.
**Screens** chart of accounts tree + dimensions, journal list/form (keyboard-fast grid entry), JournalRequest inbox & fix queue, posting rule designer (event→lines, test with sample payload), reports: trial balance 2/4/6-column (تراز), general ledger (دفتر کل), subsidiary (معین), daybook (روزنامه), tafsili ledger, account turnover, comparative periods; period close wizard; document print (سند حسابداری) template.
**AI** autofill (propose journal description/accounts from request payload — proposal), anomaly (unusual entries, round-tripping, weekend postings), nl_report ("فروش ماه گذشته به تفکیک مشتری"), explain variances. redact nothing but allow per-account redaction list.
**Iran** حساب‌های کل/معین/تفصیلی, سند موقت/دائمی, Jalali fiscal year (default 1 Farvardin) and month names, Persian digits, standard chart seed (editable, industry-neutral).
