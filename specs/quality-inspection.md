# quality-inspection — Incoming/in-process/final inspection (L3; requires item-master; optional inventory, routing, party-master)

**Entities** InspectionPlan{scope[item|category|supplier|operation],stage[IQC|IPQC|FQC|OQC],characteristics[],sampling{method[fixed|percent|aql],aql,level,table_ref},dynamic_modification_rules}; Characteristic{name,type[quantitative|qualitative|attribute],unit,lsl,usl,target,method,gauge_ref,critical_class[critical|major|minor]}; InspectionLot{number,trigger_ref,item,lot,qty,plan,status[open|in_progress|decided|closed],sample_size}; Result{lot,characteristic,sample_no,value|ok,notes,measured_by,at}; UsageDecision{accept|reject|conditional_accept|rework|scrap,notes,by}; Certificate{type[COA|COC|test_report],lot,values,attachments}; SupplierQualityStat (feed).
**Rules** lots auto-created on triggers (inventory.receipt.posted→IQC, production op completed→IPQC, production finished→FQC, shipment optional) with plan resolution by specificity (supplier+item > item > category); sample size from AQL table (configurable data table, include standard tables as seed data); quantitative results auto-judge vs limits; decision gate emits stock bucket change (accept→available, reject→blocked/return) via event; skip-lot rules by supplier score; results immutable after decision (amend by reopening with reason); certificates printable.
**Events out** quality-inspection.lot.created|decided{decision,qty split}, result.out_of_spec (NCR proposal trigger), certificate.issued. **In** inventory.receipt.posted, production.operation.completed, production.workorder.completed (events from future modules; ignore if none).
**Service contract** QualityService: lotStatus(ref), isReleased(lot), supplierScore(supplier,range), openLots(filter), spc(characteristic,range).
**Permissions** quality-inspection.plan.manage, lot.view|execute|decide, certificate.issue, report.view.
**Screens** inspection worklist (mobile-friendly result entry with limits highlighting), plan designer, lot detail & decision dialog, certificates print (print-barcode-qr), SPC charts (X-bar/R, histogram, Cp/Cpk), reject analysis Pareto, supplier quality dashboard.
**AI** anomaly (drift in measurements, suspicious perfect data), extract results from lab report text/PDF (doc-ocr, proposal), summarize lot, next_action (suggest NCR/CAPA proposal), forecast supplier risk.
**Iran** گواهی کیفیت/COA فرم‌ها, استانداردهای ملی as free-text refs, Persian sampling plan labels.
